          Reading

          Line focus

          Switch on with the Line focus button in the header. Move the pointer to highlight a line, click to lock it, then use the arrow keys to move it. Esc releases the lock.

          Layout

          Voice

          The natural voice is a one-time download kept in your browser: about 90 MB, or about 330 MB with GPU, which is much faster. Each voice also fetches a small file the first time you use it. The browser voice needs no download.

          Lookup

          Select a word or passage in the book and choose “Ask Claude” for a short explanation. This uses your own Anthropic API key (from the Claude Console), so lookups are paid from your own credits.

          The key is stored only in this browser and sent only to api.anthropic.com. Anyone using this browser profile or its developer tools can read it, so use it on your own devices and set a spending limit in the Console.
